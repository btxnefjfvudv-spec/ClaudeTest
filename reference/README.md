# ข้อมูลอ้างอิงจากผู้ใช้

ส่งในแชทได้เลย ผมจะเก็บไว้ใน `reference/photos/` (โฟลเดอร์นี้ **ไม่ขึ้น GitHub** เพราะ repo เป็น public)

## ที่ต้องการ

1. รูปบรรยากาศห้อง 5/8 (มุมกว้าง)
2. รูปมุมต่าง ๆ: กระดาน, โต๊ะครู, โต๊ะ/เก้าอี้นักเรียน, หน้าต่าง, ประตู, พัดลม, ตู้, ของตกแต่ง
3. ผังที่นั่ง (รูปหรือพิมพ์มา): ชื่อ, เลขที่, แถว, ตำแหน่ง
4. รายชื่อเพื่อน (ชื่อเล่นที่จะโชว์ในเกม)
5. รูปเพื่อน (ถ้ามี) — ใช้แค่ดู ทรงผม / สีผม / ชุด / จุดเด่น

ถ้าอ่านชื่อหรือตำแหน่งไม่ชัด ผมจะถามก่อน ไม่เดาเอง
