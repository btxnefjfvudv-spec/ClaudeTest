# Project rules (CLASSROOM 5/8 PARTY)

- **Every finished task = a checkpoint:** add a line to `docs/CHECKPOINTS.md`, then `git commit` and `git push` right away. Never leave finished work uncommitted.
- Characters always wear the regular **white school uniform** (the mint shirts in the photos are activity shirts). Keep each friend's own hair, face, build and small details (glasses, earbuds, braces, collar-star colour).
- Real photos of classmates stay local in `reference/photos/` (gitignored — the repo is public). Never commit them.
- Do not draw royal portraits or religious images from the classroom photos.
- Follow `docs/MINIGAME_DEV_GUIDE.md` for minigames; run `node tools/smoke.cjs` before committing game changes.
