# ผู้ช่วยลงทะเบียนวิชาเลือก (E-Enrollment Assistant)

โปรแกรมช่วยเตรียมตัวและลงทะเบียนวิชาเลือกบนเว็บ
[myzma68.com/rw_enrollment/_site/](https://myzma68.com/rw_enrollment/_site/)
ให้เร็วขึ้นและพลาดน้อยลง

**โปรแกรมทำให้:**
- เปิดเบราว์เซอร์ไปที่เว็บโรงเรียน (เข้าสู่ระบบเองในหน้าต่างนั้น)
- อ่านตารางรายวิชา แล้วจับคู่กับวิชาที่ตั้งไว้ด้วยรหัสวิชา
- เฝ้ารอเวลาเปิดตามนาฬิกาของเว็บโรงเรียน แล้วโหลดหน้าใหม่ทันทีที่ถึงเวลา
- ไฮไลต์แถววิชาที่ต้องการในเบราว์เซอร์ และแจ้งเตือนด้วยเสียง
- กดปุ่มบนเว็บให้ 1 ครั้ง หลังจากคุณกดยืนยันที่หน้าควบคุม (หรือจะกดเองในเบราว์เซอร์ก็ได้)
- ตรวจผลจากตาราง "ข้อมูลรายวิชาที่ลงทะเบียน" บนเว็บ และเก็บภาพหน้าจอเป็นหลักฐาน

**โปรแกรมไม่ทำ:**
- ไม่รับและไม่เก็บรหัสผ่าน/เลขบัตรประชาชน (คุณพิมพ์เองในเว็บโรงเรียน)
- ไม่ข้ามระบบยืนยันตัวตน CAPTCHA หรือคิว
- ไม่ส่งคำขอรัว ๆ: ตรวจซ้ำได้ไม่ถี่กว่าทุก 5 วินาที และหยุดเองเมื่อครบจำนวนครั้ง
- ไม่กดลงทะเบียนวิชาเดิมซ้ำ จนกว่าจะ "ตรวจผล" แล้วพบว่ายังไม่สำเร็จ
- ไม่บอกว่า "สำเร็จ" ถ้าเว็บยังไม่แสดงวิชานั้นในรายการที่ลงทะเบียน
- ไม่เปลี่ยนเวลาเครื่อง

> ⚠️ ไม่ควรส่งรหัสผ่านหรือเลขบัตรประชาชนให้ใคร รวมถึงแชตบอต โปรแกรมนี้ไม่ต้องใช้ข้อมูลเหล่านี้

## สิ่งที่ตรวจพบจากเว็บจริง

ตรวจจาก HTML หน้า "ลงทะเบียนวิชา" ที่บันทึกไว้ (22 ต.ค. 2569 ตอนระบบยังไม่เปิด) และภาพหน้าจอหน้า "หน้าแรก"

| ส่วน | สิ่งที่พบ | ยืนยันแล้ว? |
|---|---|---|
| หน้าลงทะเบียน | `index.php?sop=std_register_course` | ✅ |
| ตารางรายวิชา | คอลัมน์ ลำดับ / รหัสวิชา / ชื่อวิชา / หน่วยกิต / เลือก sec | ✅ |
| ระบบยังไม่เปิด | ช่อง "เลือก sec" ขึ้นว่า **ไม่ถึงเวลาเลือก** | ✅ |
| เข้าสู่ระบบแล้ว | เมนูมีลิงก์ "ออกจากระบบ" (`sop=logout`) | ✅ |
| หน้าแรก (ผลการลงทะเบียน) | `index.php?sop=profile_student` ตาราง "ข้อมูลรายวิชาที่ลงทะเบียน" (รหัสวิชา, section, ชื่อวิชา, ...) ว่างจะขึ้น "ไม่พบข้อมูลการลงทะเบียน" | ✅ จากภาพหน้าจอ (ยังไม่เห็น HTML) |
| ช่อง "เลือก sec" ตอนระบบเปิด | เป็นลิงก์ ปุ่ม หรือรายการเลือก? | ❌ ยังไม่เคยเห็น |
| หน้าต่างยืนยัน / ข้อความหลังกด | | ❌ ยังไม่เคยเห็น |
| ข้อความตอนวิชาเต็ม | ตั้งไว้ว่าคำว่า "เต็ม" | ❌ เดาไว้ ยังไม่ยืนยัน |
| หน้าเข้าสู่ระบบ | | ❌ ยังไม่เคยเห็น (ไม่จำเป็น เพราะคุณล็อกอินเอง) |

เพราะยังไม่เคยเห็นหน้าเว็บตอนระบบเปิด โปรแกรมจึงไม่เดาว่าต้องกดอะไร
ตอนระบบเปิด โปรแกรมจะหาปุ่ม/ลิงก์ที่อยู่ในช่อง "เลือก sec" ของแถววิชาที่ต้องการ แล้วแสดงให้คุณเลือกเอง
ถ้าเว็บมีขั้นตอนต่อ (เช่น หน้าเลือก section) ให้ทำต่อในเบราว์เซอร์ แล้วกด "ตรวจผล"

## ติดตั้ง (Windows)

1. ติดตั้ง **Node.js** รุ่น LTS จาก <https://nodejs.org> (กด Next ไปจนจบ)
2. ดาวน์โหลดโปรเจกต์นี้ (ปุ่ม **Code → Download ZIP** บน GitHub) แล้วแตกไฟล์ไว้ เช่นที่ `เอกสาร\enrollment`
3. ดับเบิลคลิก **`start.bat`**
   - ครั้งแรกจะติดตั้งส่วนประกอบเอง (ต้องต่ออินเทอร์เน็ต รอ 1–2 นาที)
   - หน้าควบคุมจะเปิดในเบราว์เซอร์ที่ <http://127.0.0.1:3939>
4. ปิดโปรแกรม: ปิดหน้าต่างสีดำ หรือกด `Ctrl + C`

โปรแกรมจะเปิด Google Chrome หรือ Microsoft Edge ที่มีในเครื่อง (แยกโปรไฟล์จากที่ใช้ประจำ)

macOS / Linux: เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ `npm install` ครั้งแรก จากนั้น `npm start`

## ตั้งค่ารายวิชา

1. กด **1. เปิดเบราว์เซอร์** แล้วเข้าสู่ระบบในหน้าต่างที่เปิดขึ้น
2. กด **2. ตรวจสถานะตอนนี้** โปรแกรมจะอ่านรายวิชาจากเว็บ
3. ในส่วน **ตั้งค่า** เปิด "เลือกจากรายวิชาที่อ่านได้จากเว็บ" แล้วกด **+ หลัก** หรือ **+ สำรอง** (ไม่ต้องพิมพ์รหัสเอง)
4. เรียงลำดับความสำคัญด้วยปุ่ม ↑ ↓ (บนสุดสำคัญที่สุด)
5. ใส่ **วันและเวลาเปิดลงทะเบียน** ตามประกาศโรงเรียน และ **จำนวนวิชาที่ต้องลง**
6. กด **บันทึกการตั้งค่า**

ตัวเลือก:
- **ถ้าวิชาหลักเต็ม ให้ใช้วิชาสำรองได้เลย** — ถ้าไม่ติ๊ก โปรแกรมจะแค่เสนอวิชาสำรอง และรอให้คุณกด "ใช้วิชาสำรอง"
- **อนุญาตให้โปรแกรมกดปุ่มบนเว็บแทน** — ถ้าไม่ติ๊ก โปรแกรมจะแค่ไฮไลต์แถว ให้คุณกดเองในเบราว์เซอร์
- **ตรวจซ้ำทุก** (ค่าเริ่มต้น 10 วินาที, อย่างน้อย 5) และ **ตรวจซ้ำสูงสุด** (ค่าเริ่มต้น 60 ครั้ง)

การตั้งค่าจะถูกเก็บใน `data/settings.json` บนเครื่องนี้เท่านั้น

## ซ้อมก่อนวันจริง (แนะนำ)

มีเว็บจำลองที่หน้าตาเหมือนเว็บจริงไว้ซ้อม ไม่มีการส่งข้อมูลไปที่เว็บโรงเรียน

1. เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ `npm run mock`
2. เปิดโปรแกรมด้วย `start.bat` แล้วเปลี่ยน **URL เว็บไซต์** เป็น `http://127.0.0.1:4000/rw_enrollment/_site/` แล้วบันทึก
3. กดเปิดเบราว์เซอร์ แล้วเข้าสู่ระบบในเว็บจำลอง (พิมพ์อะไรก็ได้)
4. เปิด <http://127.0.0.1:4000/__test/> เพื่อกด "เปิดระบบ", "ให้วิชาเต็ม", "ทำให้เซสชันหมดอายุ" ฯลฯ แล้วดูว่าโปรแกรมตอบสนองอย่างไร
5. ซ้อมเสร็จ เปลี่ยน URL กลับเป็น `https://myzma68.com/rw_enrollment/_site/`

## วันลงทะเบียน

**ก่อนเวลาเปิด 15–30 นาที**
1. ดับเบิลคลิก `start.bat`
2. กด **เปิดการแจ้งเตือน** (เพื่อให้มีเสียงเตือน) และเปิดเสียงลำโพง
3. กด **1. เปิดเบราว์เซอร์** แล้วเข้าสู่ระบบ
4. กด **2. ตรวจสถานะตอนนี้** ควรเห็นสถานะ `WAITING` (ยังไม่ถึงเวลาเปิด)
5. ตรวจว่าวันและเวลาเปิดถูกต้อง แล้วกด **3. เริ่มเฝ้ารอเวลาเปิด**

**ระหว่างรอ**
- โปรแกรมจะไม่ส่งคำขอไปที่เว็บ ยกเว้นตรวจความพร้อมตอน 10 นาที และ 2 นาทีก่อนเปิด
- ถ้ามีเสียงเตือนว่า "ต้องเข้าสู่ระบบ" ให้เข้าสู่ระบบใหม่ในเบราว์เซอร์
- อย่าปิดหน้าต่างเบราว์เซอร์ที่โปรแกรมเปิด

**ถึงเวลาเปิด**
1. โปรแกรมโหลดหน้าลงทะเบียน ถ้ายังขึ้น "ไม่ถึงเวลาเลือก" จะลองใหม่ทุก 10 วินาที
2. เมื่อเปิดแล้ว จะมีเสียงเตือน สถานะเป็น `CONFIRMATION_REQUIRED` และแถววิชาในเบราว์เซอร์ถูกไฮไลต์สีส้ม
3. ตรวจรายการในตาราง **แผนการลงทะเบียน** แล้วเลือกทางใดทางหนึ่ง:
   - กดปุ่มสีส้ม **ลงทะเบียน: "..."** → อ่านข้อความ → **ยืนยัน กดให้เลย** หรือ
   - กดเองในเบราว์เซอร์ที่แถวสีส้ม
4. **ถ้าเว็บถามยืนยัน (เช่น "ยืนยันการลงทะเบียน?") หน้าต่างคำถามจะขึ้นที่หน้าควบคุม ไม่ใช่ในเบราว์เซอร์** อ่านแล้วกด ตกลง/ยกเลิก
   (ข้อความแจ้งเตือนแบบมีปุ่มตกลงอย่างเดียว โปรแกรมจะกดตกลงให้และแสดงข้อความไว้ใน "ข้อความจากเว็บ")
5. ถ้าเว็บมีขั้นตอนต่อ ให้ทำในเบราว์เซอร์จนเสร็จ
6. กด **5. ตรวจผล** — ถ้าเห็น `SUCCESS` และตาราง "ผลการตรวจจากเว็บไซต์" มีวิชานั้น แปลว่าสำเร็จ (มีภาพหลักฐานในโฟลเดอร์ `evidence`)
7. ถ้ายังไม่สำเร็จ ปุ่มลงทะเบียนจะกลับมาให้กดได้อีกครั้ง หรือใช้วิชาสำรอง

> แนะนำให้กด **บันทึกโครงสร้างหน้านี้** ตอนอยู่หน้าลงทะเบียนที่ระบบเปิดแล้ว ไฟล์จะอยู่ในโฟลเดอร์ `captures` ใช้ปรับโปรแกรมให้แม่นขึ้นในเทอมหน้า (ไฟล์อาจมีชื่อนักเรียน อย่าแชร์สาธารณะ)

## ความหมายของสถานะ

| สถานะ | ความหมาย |
|---|---|
| `READY` | พร้อม เข้าสู่ระบบแล้ว (ยังไม่ได้เลือกวิชา) |
| `WAITING` | ยังไม่ถึงเวลาเปิดลงทะเบียน |
| `LOGIN_REQUIRED` | ต้องเข้าสู่ระบบ หรือเซสชันหมดอายุ |
| `COURSE_AVAILABLE` | พบวิชาที่ต้องการและยังเปิดรับ |
| `COURSE_FULL` | วิชาเต็ม (จะเสนอวิชาสำรองถ้ามี) |
| `CONFIRMATION_REQUIRED` | รอคุณตรวจและยืนยัน |
| `SUCCESS` | เว็บแสดงวิชาในรายการที่ลงทะเบียนแล้ว |
| `FAILED` | ไม่สำเร็จ เช่น เว็บแจ้งข้อผิดพลาด โหลดช้าเกิน ไม่พบวิชา |
| `UNKNOWN` | ยังยืนยันไม่ได้ เช่น กดแล้วแต่ยังไม่มีหลักฐาน → กด "ตรวจผล" |

## ไฟล์ที่โปรแกรมสร้างในเครื่อง

| โฟลเดอร์/ไฟล์ | เก็บอะไร |
|---|---|
| `data/settings.json` | รายวิชาและการตั้งค่า |
| `logs/` | บันทึกการทำงานรายวัน (ไม่มีรหัสผ่าน คุกกี้ หรือเลขบัตรประชาชน) |
| `evidence/` | ภาพหน้าจอหลักฐานผลการลงทะเบียน |
| `captures/` | โครงสร้างหน้าเว็บที่กดบันทึก (ลบค่าในช่องกรอกออกแล้ว) |
| `.browser-profile/` | ข้อมูลเบราว์เซอร์ของโปรแกรม รวมถึงการเข้าสู่ระบบ — **ห้ามส่งให้ใคร** ลบโฟลเดอร์นี้ได้หลังลงทะเบียนเสร็จ |

ทั้งหมดนี้ไม่ถูกอัปโหลดขึ้น Git (อยู่ใน `.gitignore`)

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `start.bat` บอกว่าไม่พบ Node.js | ติดตั้ง Node.js LTS แล้วเปิดใหม่ |
| เปิดเบราว์เซอร์ไม่ได้ | ตั้ง "เบราว์เซอร์" เป็น Microsoft Edge หรือ ถ้าเลือก Chromium ให้รัน `npx playwright install chromium` ก่อน |
| พอร์ต 3939 ถูกใช้อยู่ | โปรแกรมเปิดอยู่แล้ว เปิด <http://127.0.0.1:3939> หรือปิดหน้าต่างเก่า |
| สถานะ `UNKNOWN` "ไม่พบตารางรายวิชา" | หน้าเว็บอาจเปลี่ยน ให้กด "บันทึกโครงสร้างหน้านี้" แล้วนำไฟล์มาปรับ `config/site-profile.json` |
| กดในเบราว์เซอร์แล้วไม่มีอะไรเกิดขึ้น | ดูที่หน้าควบคุม อาจมีคำถามยืนยันจากเว็บรอให้ตอบ |
| "เพิ่งโหลดหน้าเว็บไป รออีก X วินาที" | ระบบป้องกันการส่งคำขอถี่ รอแล้วกดใหม่ |

## สำหรับนักพัฒนา

```
config/site-profile.json   ข้อความ/หัวตารางของเว็บจริงที่โปรแกรมใช้อ่านหน้า (แก้ตรงนี้ถ้าเว็บเปลี่ยน)
src/extract.js             โค้ดที่รันในหน้าเว็บ อ่านตารางวิชาและตารางวิชาที่ลงแล้ว
src/planner.js             แปลงข้อมูลหน้าเว็บเป็นสถานะ และวางแผนเลือกวิชา (หลัก/สำรอง)
src/matcher.js             จับคู่วิชาด้วยรหัสก่อน ชื่อเป็นรอง ไม่เลือกชื่อที่แค่คล้าย
src/scheduler.js           ตัดสินใจว่าเมื่อไรควรโหลดหน้า (ฟังก์ชันบริสุทธิ์)
src/assistant.js           ตัวควบคุมหลัก: ล็อกงาน, จำกัดความถี่, กันกดซ้ำ, ตรวจผล
src/browser.js             ห่อ Playwright (เปิดเบราว์เซอร์, หน้าต่างยืนยัน, เวลาเซิร์ฟเวอร์)
src/server.js              API ของหน้าควบคุม (ฟังเฉพาะ 127.0.0.1)
public/                    หน้าควบคุม
test/mock-site/            เว็บจำลองที่เลียนแบบโครงสร้างเว็บจริง
test/fixtures/             HTML หน้าลงทะเบียนจริง (ตัดส่วนตกแต่งออก)
```

ทดสอบ: `npm test` (ต้องมี Chromium ของ Playwright: `npx playwright install chromium`)
