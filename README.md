# ศึกสี่มุม

ปาร์ตี้มินิเกมสำหรับ 2–4 คน เล่นพร้อมกันบนไอแพดเครื่องเดียว (วางไอแพดแนวนอนบนโต๊ะ นั่งฝั่งละ 2 คน)

## วิธีเล่น
1. เปิด `index.html` ใน Safari บนไอแพด
2. แต่ละคนแตะช่องของตัวเองเพื่อเข้าร่วม แล้วกดปุ่ม ▶ กลางจอ
3. เล่น 5 มินิเกม: แตะให้ไว · รัวนิ้ว · สีหลอกตา · หยุดที่ 5 วินาที · เก็บดาว
4. ที่ 1 ได้ 3 คะแนน ที่ 2 ได้ 2 ที่ 3 ได้ 1 คะแนนรวมสูงสุดเป็นแชมป์

เคล็ดลับ: กด “แชร์ → เพิ่มไปยังหน้าจอโฮม” ใน Safari จะได้แบบเต็มจอเหมือนแอป
